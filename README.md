# Multi-Tenant Marketing Intelligence Platform — 3D Architecture Visualizations

Interactive 3D WebGL architecture blueprints and cinematic tour presentations for the Multi-Tenant Marketing Intelligence Platform.

## 🚀 Live Visualizations

- **Portal (Both Views)**: `index.html`
- **High-Level Architecture (Command Center)**: `High-Level-Architecture-3D.html`
  - Radial command-center view with all 34 components across 8 zones
  - Explicit **START ➔ END** data flow paths with animated particles and directional arrows
  - 50-second automated camera tour
  - Dependency spotlight on click
- **System Architecture (Cinematic Tour)**: `System-Architecture-3D-Visual.html`
  - 6-layer stacked isometric platform
  - 40-second phase-by-phase build plan animation
  - Unreal Engine bloom post-processing

## 🛠 Tech Stack

- **Three.js** (WebGL 3D Rendering)
- **PostProcessing** (UnrealBloomPass)
- **CSS2DRenderer** (Dynamic 3D Labels)
- **OrbitControls** (Interactive Orbit, Pan, Zoom)
